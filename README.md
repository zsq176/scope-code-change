# scope-code-change

用于执行代码变更的分阶段 skill。它要求先查清系统影响，再制定精确计划、验证关键机制、实施、审计并清理。完整执行规则以 [SKILL.md](SKILL.md) 为准。

## 流程

1. **全系统影响矩阵**：沿生产者、状态和消费者追踪当前行为，说明受影响和不受影响的子系统。
2. **原子化计划**：逐项目标写明证据、`文件:行号`、具体修改、验收方式和成本。
3. **经验门禁**：用适用的经验规则检查计划；必要时输出完整修订版。
4. **有效性门禁**：用复现、测量或对照实验验证关键机制；证据不足时返回调查。
5. **实施**：仅在用户授权代码变更时执行，并逐项目标完成验证。
6. **代码审计**：将实际改动映射回计划，检查缺陷、回归和验收证据。
7. **清理**：删除临时产物、被替代的路径和多余复杂度；纯方案任务也要经过此门禁。

每一阶段都要报告结果、退出条件、`PASS` / `FAIL` 审计结论，以及下一阶段或返回阶段。纯方案请求在通过有效性门禁后跳过实施和代码审计。未经授权，不进行生产代码修改、部署或真实交易。

## 使用

将本仓库目录放入 Codex 的 skills 目录，并在请求中指定 `$scope-code-change`。`agents/openai.yaml` 提供该 skill 的界面元数据。
